# NetLearn Labs

A beginner-friendly, interactive learning app for **networking fundamentals**:
- **Subnetting** (IP + mask → ranges + binary visualization + quiz)
- **Routing** (topology visualization + routing table + shortest path)
- **TCP** (3-way handshake animation + congestion window visualization + state machine)

This is designed to be deployable to **GitHub Pages** (uses a `HashRouter`).

## Run locally
```bash
cd /Users/sanketgautam/clawd/projects/netlearn
npm install
npm run dev
```

## Tech Stack
- React + Vite
- React Router
- Tailwind CSS
- Canvas API

## Course alignment note
Subnetting, routing, and TCP reliability/congestion control are core topics in most
network systems courses (including UW CSEP-561 fundamentals).
